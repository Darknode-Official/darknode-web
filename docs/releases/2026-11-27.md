## What changed (user-visible)
- Self-service account deletion. Deck Settings > Data > Delete account, the older settings page, and the "Verify your email" screen (unverified sign-ups had no way out). The user types DELETE and signs in again if the sign-in is older than 5 minutes. Then this account's data is cleared from the browser; other accounts on the same browser keep theirs.
- Worker `POST /api/account/delete` removes, in order:
  - the personal workspace's graph, monitors (including the free watch) and API keys;
  - team workspaces and vaults the user holds alone;
  - their member docs elsewhere;
  - every Firestore record naming them;
  - then the Firebase Auth account, last.
  If the user created a workspace that still has members, it refuses with 409 and names it, before anything is touched. Running it again finishes a deletion that stopped partway.
- Terms, Privacy and Docs describe the self-service path. Wording only, no TOS_VERSION bump.
- `/legal/terms-of-service.html` was an unfilled template (21 "[SPECIFY ...]" placeholders) served publicly. It's moved to `unused-stuff/`, and the URL 301s to `/terms` on both hosting sites.

## Security / rules / data changes
- New user route `/api/account/delete`. Each Durable Object has an internal `/__wipe` route; user-facing forwards always build fixed paths, so outside input can't reach it.
- No Firestore or Storage rules change. No new secrets, bindings or migrations. Strict CSP header unchanged.
