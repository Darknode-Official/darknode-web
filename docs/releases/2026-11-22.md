# Release 2026-11-22

Build 353f24ab41fd, Worker darknode-proxy 27946f43 (staging 5ef542af). PR #132 (includes #129 and #131), merge 9b6767de, tag v2026.11.22.

## What changed (user-visible)
- Sign-up: accepting the Terms now saves even when the first profile write failed. The TOS write includes `email`, which the users/{uid} create rule requires. The profile write is retried once (#129).
- Monitors record who set them up. Each scheduled run re-reads that person's live plan, plan sharing included. If the plan no longer covers monitoring, the run is held, logged in history and shown with a "Held: plan" pill. Resuming a paused monitor needs the plan. If the plan can't be read, the run goes ahead (fail open) (#131).
- API keys record their creator. Ingest is refused with 402 once the creator no longer has Team. Read-back, list, revoke and drain stay open (#131).
- Admin: "New users (7 days)", the registration chart and last-active now count the Auth metadata date strings that profiles store. Avatars load only from Google/GitHub avatar hosts, with no-referrer (#131).

## Security / rules / data changes
- No Firestore rules change.
- Worker: `worker/plan-share.js`, `worker/monitor.js`, `worker/ingest.js`. Monitors and keys keep running only while the creator's plan covers them.
- Admin avatars no longer fetch arbitrary user-set photoURL hosts from the owner's browser.
